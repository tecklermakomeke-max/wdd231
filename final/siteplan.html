Project Site Plan

Teckler Makomeke - WDD 231

1. Site Name

Beaded Elegance Bags

Reason: This name shows beauty and handmade luxury. It is for beaded bags that are elegant for weddings and parties.

Optional Domain: beaded-elegance.co.za

2. Site Purpose

The site provides a hub for handmade beaded bags business by listing products, showing gallery, providing custom order information and contact form. Customers can see prices, materials, and order via WhatsApp. The site will also save wishlist in localStorage.

3. Scenarios

  • How much does a custom beaded bag cost and how long does it take to make?
  • Where can I see all available designs and colors for wedding bags?
  • How do I request a custom color pattern for my bag?

4. Color Scheme

My colors are inspired by African beads:

#4A1942 - Deep Plum - Used for headings and header background
#D4A017 - Gold - Used for accents, buttons, and highlights
#FFF8E7 - Cream - Used for page background
#2B2B2B - Dark Gray - Used for paragraph text

5. Typography

Poppins (600) - Used for all headings (h1, h2, h3)

Lora (400) - Used for body paragraphs and normal text
